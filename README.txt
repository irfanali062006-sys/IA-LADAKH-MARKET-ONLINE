IA LADAKH MARKET ONLINE — PWA PACKAGE

Brand: IA Ladakh Market Online
Tagline: Sab Kuch, Aap Ke Liye
Area: Kargil / Ladakh

FILES
- index.html: website and existing demo features
- banner.png: provided brand banner
- icons/: PWA icons made from provided app icon
- manifest.webmanifest: installable PWA metadata
- service-worker.js: basic offline app shell cache

IMPORTANT FIREBASE NOTE
Firebase values in index.html are placeholders. Replace them with your own Firebase Web App config from Firebase Console > Project settings > Your apps. This ZIP does not include a real Firebase project, API config, hosting URL, or private token. Firebase Auth, Firestore and Storage need setup and secure rules before real user data is used.

HOSTING
Upload the CONTENTS of this folder to a static HTTPS host. Do not upload only this ZIP if the host expects extracted files. After hosting, open the HTTPS URL and test the app. PWABuilder can package a hosted PWA for Android after HTTPS hosting and PWA checks.
